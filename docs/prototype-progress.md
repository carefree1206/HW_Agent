版本日期：2026-10-20。定位：让团队先体验故事与业务闭环，并检验关键约束。比赛完整版本、华为平台接入、模型训练仍按总体计划继续。

这是 v0.1 的历史交付记录。当前实现与最新验证见 [v0.2 迭代记录](iteration-v02.md) 和根目录 README。

## 本轮交付

五个可操作页面：指挥中心、现场报告、方案与资源、回执中心、运行记录。应用采用 React/TypeScript + FastAPI + SQLite，普通 CPU 可运行，无 GPU 依赖。

真实运行部分：HTTP 工具调用、有限模型路径计算、资源检查、批准、文件保存、消息队列、终端/人员回执、离线暂存、持久化、记录导出。

演练合成部分：地名人口、道路、监测节点响应、资源投放与链路恢复。角色处理采用确定性规则，没有模型推理；没有产生华为平台 Trace。

## 当前求解模型

固定的 12 个区域、18 条道路、2 支队伍。每队在本时窗仅执行一个任务；便携设备需在领取点取用，电量覆盖行程、部署与 20 分钟预留。先枚举任务到队伍的有限分配，再计算开放道路最短路，并按目标函数选取方案。返回的“最优”仅限该声明的有限模型。

未建模无线传播、道路容量、连续时间交通、概率灾情及人员安全；移动电源未参与自动调度。R10 拥塞保留为观察项，不能宣称全部网络问题已解决。执行时推进演练时钟，真实 HTTP 记录使用真实墙钟，二者分开保存。

## 下一轮与华为平台对接

1. 用参赛账号、可用地域与服务跑通 `wf_ping`，验证已发布 AgentArts 工作流 → 自研 MCP → 返回值 → 平台 Trace。
2. 接 SIS/视觉模型；对真实授权素材生成带时间、来源、不确定性的结构化观测。保留原文和人工更正入口。
3. 建设有版本的正式知识语料、嵌入、混合检索与引用验证；用向量 RAG 替换当前 4 条演练规则检索。
4. 用数据计划冻结训练/开发/盲测划分，再开展领域抽取 LoRA；对比基础模型、提示词、RAG 与微调的增量。
5. 接入独立场景真值和批量评测，加入信息缺失、过期证据、工具失败与资源不可行；产生可复现的结果。

本轮没有申请付费资源、调用云模型或启动训练，没有对外发送任何灾情/应急消息。
